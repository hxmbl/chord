Chord

Connect Linear together with the tools you use to build.

Chord is a small orchestration layer for connecting project tracking with coding tools and agents.

Run

Requires "uv" (https://docs.astral.sh/uv/).

uv sync
uv run main.py

Direction

Chord starts with one simple goal:

Connect project updates to the tools that act on them.

The first implementation will focus on receiving updates from the project's source of truth, gathering the relevant context, and connecting that context to coding tools.

Start small. Build outward.
